## 1. 总体架构

新增一层 `WorldBuilder`（`src/WorldBuilder.gd`，class_name `WorldBuilder`），由 `Arena` 持有：

```
Arena
├─ Board（不变：环道 / 终点跑道 / 基地 / 中央台 / 骰子）
├─ World（WorldBuilder 生成，随场景整组重建）
│   ├─ Terrain     地面/水面/熔岩/虚空/沙丘/黄铜地板
│   ├─ Horizon     远景体量（山、云海、冰峰、熔岩柱、雨林、星环、沙丘、钟塔）
│   ├─ Props       近景道具（树、拱门、冰晶、柱、雕像、浮石、方尖碑、齿轮）
│   └─ Atmosphere  该场景专属光源 + 环境粒子锚点
└─ FX（不变：所有演出原语）
```

- `set_theme(id)`：环境/材质参数照旧；若 `scene` 变化，`World` 整组 `queue_free()` 后重建（只在菜单预览与开局时发生，游戏中不切场景）。
- `_build_ground()` / `_build_scenery()` 迁移进 `WorldBuilder`，`Arena` 只保留转发。
- 棋盘融合由 `Arena._apply_board_skin()` 处理：按场景切换 `PlazaSkirt` 可见性、边缘环材质与「边缘道具」（火盆/齿轮齿/冰冠/藤蔓/沙堆/浮石锚点）。

**不改的东西**：环道点位、终点跑道对齐、相机取景、棋子建模、存档、LAN 帧格式、HUD 主体布局。

设计原则（逐条对应「不能只换配色」）：
1. **地平线高度不同**：草地/冰湖/熔岩/黄铜 = 平视地平线；浮岛/虚空 = 无地平线、只有云海或星云。
2. **体量构图不同**：树（竖直有机）、拱门（竖直框架）、冰峰（尖锐）、玄武柱（粗壮）、雨林台阶（水平层叠）、浮石（散点）、沙丘（水平曲线）、齿轮（圆形机械）。
3. **主光来源不同**：天光 / 低角度长影 / 冷高光 / 地底光 / 斑驳顶光 / 边缘光 / 硬日光 / 室内暖灯。
4. **棋盘与世界的关系不同**：贴地广场 / 悬空台 / 冰封圆盘 / 熔岩堤道 / 祭坛 / 漂浮残骸 / 下沉神庙 / 机关盘。

### 2.1 每场景技术实现要点

- **地形**：`PlaneMesh`（草地/冰/熔岩/黄铜）或程序化网格（沙丘用 3 圈 `CylinderMesh` 压扁后随机扰动 y）。
- **熔岩/冰/极光/符文/蒸汽**：`ShaderMaterial` + `TIME`，纯 GLES3 语法，不用 SSBO / 计算着色器。熔岩 = 两层噪声 UV 反向滚动 + 自发光；冰 = 低透明度 + 裂纹噪声 + 菲涅尔；极光 = 3 张竖直平面叠加 `sin` 偏移。
- **道具批量**：树/灌木/冰晶/浮石/柱按 `MultiMesh` 或复用 `_add_*` 生成；单场景新增 Mesh 控制在 **140 个以内**，投阴影的只保留主光下的近景大件（≤30）。
- **光源**：每场景除 `Sun` + `Fill` 外最多 +2 个 `OmniLight3D`（熔岩底光、黄铜壁灯），移动端不新增阴影光源。
- **氛围粒子**：沿用现有 `MultiMesh` 手写粒子（不引入 GPUParticles），每场景 36–56 实例，按场景给不同运动公式。

## 5. 技术取舍与限制（如实说明）

| 想做的 | 结论 | 替代方案 |
|---|---|---|
| 真实体积雾 / 丁达尔光 | Mobile 渲染器 + 省电约束下代价过高 | 半透明雾片 + 低密度 `Environment.fog` |
| 实时反射（冰湖/水面） | 需额外视口，移动端翻倍开销 | 低透明度镜像色块 + 高光片 + 菲涅尔自发光 |
| 布料/骨骼动画 | 棋子为程序化拼装，无骨骼 | 对 `Body/Cape/Banner/Plume` 做分段 tween（披风摆动、旗帜抖动） |
| 熔岩真实流体 | 无 | 双层噪声 UV 滚动 + 自发光 + 火花粒子 |
| GPUParticles3D | 移动端发热风险 | 继续用 MultiMesh 手写粒子，数量上限 56 |
| 阴影 | 只保留主光，且仅近景大件投阴影 | 道具用接地软阴影贴片 |

## 6. 兼容性
