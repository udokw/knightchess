# 验收清单 · 7 项体验修正

## 1. 终点跑道对齐
- [x] `_apply_board_size(n)` 的起始角为 `360/n - 180` 度，且注释写明推导。
- [x] 40 / 52 / 64 格下，四条跑道入口与对应环道末格中心线重合。
- [x] cozy / dusk / frost / ember / jade / void 六套主题各核一遍。

## 2. 棋盘放大与布局
- [x] `_fit_camera()` 使用 fov 34、pitch 50°、`3040*(1+0.55*(grow-1))`、目标偏移 85。
- [x] 道具栏宽度为 320，折叠把手同步。
- [x] 1280×720 截图：环道占宽 ≥85%，单格 ≥40px，整盘（含四角基地）在屏内。

## 3. 动画节奏与吃棋成滩
- [x] 全局 `BASE_TIME_SCALE = 0.9`，吃棋慢动作结束回到该值，无写死 `1.0`。
- [x] 吃棋演出含蓄力/跃起/滞空/砸落/压扁/溅开/收势七阶段，总真实时长 2.2–2.6s。
- [x] 被吃棋子最终回基地，`scale / rotation / modulate` 无残留。
- [x] 荆棘：尖刺升起 → 震动 → 逐格后退，总时长 ≤1.5s。
- [x] 传送：吸入 → 传送门爆发 → 喷出落位，总时长 ≤1.5s。

## 4. 手动存档选槽
- [x] 「保存进度」打开选槽页，只列 1..19，0 号自动槽不出现且不可写。
- [x] 已占用槽需二次确认（2.5s 窗口），取消不写入。
- [x] 保存后 toast 显示具体槽号，载入页立即可见。
- [x] 自动存档仍每回合写入 0 号槽，未被手动占用。

## 5. 吃棋小游戏对决
- [x] 设置页有「吃棋对决」开关，prefs 键 `duel`，默认关闭。
- [x] 开启后：胜 → 吃棋生效；负/平 → 攻击方退回吃棋前一格，守方不动。
- [x] 4 秒倒计时到点自动随机出拳，不阻塞回合。
- [x] 关闭时吃棋行为与改动前一致。
- [x] LAN：客机为攻方时面板在客机弹出，房主 5s 超时兜底，双方最终状态一致。

## 6. 道具使用 3D 演出
- [x] 17 件道具各自有「施法 → 传递 → 受击 → 结果」四段身体动画，非单纯闪粒子。
- [x] 状态写入发生在动画命中帧，不是先改数据后播放。
- [x] 顶部文字条只补齐「谁 → 对谁 → 道具 → 效果」，不拦输入、不遮挡棋盘中心。
- [x] 狙击/炸弹/冰冻/换位逐帧截图可见完整过程；护盾/加速各 3 帧。
- [x] 连续施放两件道具不叠加、不卡回合。

## 7. 换位道具
- [x] 棋子有 `lane / lslot`，`_piece_cell_pos` 优先通道，`_legal_moves` 跳过通道内棋子。
- [x] `finished` 由 `lane == team` 推导，`_check_win` 使用同一条件。
- [x] 换位候选池包含通道内敌方棋子（只排除基地），标题标注「已到达终点区」。
- [x] 普通格 ↔ 普通格：双方同时沿弧线交叉互换，落地帧写数据。
- [x] 对方在其自己通道：拽出到己方原格并恢复可行动，己方不动，战报正确。
- [x] 对方在我方通道 / 我方在对方通道 / 通道 ↔ 普通格交叉：结果符合规格 7.4 表，无非法占位。
- [x] 存档写入 `l / ls`，读档后 `lane/lslot/finished` 一致，旧档可迁移。
- [x] `--selftest-swap` 四场景断言全过。
